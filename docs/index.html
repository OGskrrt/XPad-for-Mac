Your Xbox 360‑style controller, in Chrome on Mac.

XPad is a free Chrome extension for controllers macOS doesn't recognize: Xbox 360 pads and XInput receivers like the 8BitDo Ultimate C 2.4G. Browser games see a real gamepad, with analog sticks and triggers. No driver, no kernel extension, no security changes.

Install in three steps

  1. Download

    Download the ZIP and double-click it to unzip.

  2. Load in Chrome

    Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the extension folder.

  3. Connect and play

    In the XPad tab, click Connect controller and pick your controller. Keep that tab open and play.

Why your controller isn't detected

Macs support standard HID gamepads plus Xbox One/Series, PlayStation and MFi controllers. Xbox 360 controllers, and many third-party pads in “X-input” mode, use a different USB protocol called XInput. macOS has no driver for it: the controller shows up in System Information, yet Chrome and games ignore it. The old fix, the 360Controller kernel extension, is no longer maintained and needs lowered security on Apple Silicon.

XPad reads the controller with Chrome's WebUSB and presents it to every tab as a standard Xbox 360 gamepad.

Questions

Which controllers work?

USB controllers and receivers that use the Xbox 360 (XInput) protocol: wired Xbox 360 controllers and third-party pads in X-input mode. Tested with the 8BitDo Ultimate C 2.4G. Xbox One/Series, PlayStation and Switch Pro controllers already work in Chrome on macOS.

Which games?

Any web game or cloud gaming site that uses the standard Gamepad API. Tested with nfsu2.xyz and hardwaretester.com.

Safari or Firefox?

No, XPad needs WebUSB. Chrome and other Chromium browsers (Edge, Brave, Arc) work.

Why must the XPad tab stay open?

Some sites block USB access in their own pages, so XPad reads the controller in its own tab and passes the input to your game tabs.

It says the controller is in use.

Only one program can use a USB controller at a time. Close the other app or the second XPad tab.

Privacy?

XPad has no network access and collects nothing.
