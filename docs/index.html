Three steps

  1. Install

    Open the DMG and drag XPad into Applications.

  2. Open it once

    macOS can't verify free apps that aren't paid-signed. Go to System Settings › Privacy & Security and click Open Anyway. Only the first time.

  3. Plug in and play

    Connect the controller or its receiver. Turn on Use as keyboard & mouse and allow XPad under Accessibility.

Why your controller isn't detected

Macs support standard HID gamepads plus Xbox One/Series, PlayStation and MFi controllers. Xbox 360 controllers, and many third-party pads in “X-input” mode, use a different USB protocol called XInput. macOS has no driver for it: the controller shows up in System Information, yet games, Chrome, Safari and Steam ignore it. The old fix, the 360Controller kernel extension, is no longer maintained and needs lowered security on Apple Silicon.

XPad reads the controller directly from user space with Apple's IOUSBHost framework and sends keyboard and mouse input that every app understands.

Questions

Which controllers work?

USB controllers and receivers that use the Xbox 360 (XInput) protocol: wired Xbox 360 controllers and third-party pads in X-input mode. Tested with the 8BitDo Ultimate C 2.4G. Xbox One/Series, PlayStation and Switch Pro controllers already work on macOS without XPad.

Does it work on Apple Silicon?

Yes, on M1, M2, M3 and M4 Macs as well as Intel Macs, with macOS 13 Ventura or later.

Do I need to disable SIP or install a driver?

No. Nothing is installed into the system. Quit XPad and your Mac is exactly as before.

Why does it ask for Accessibility permission?

macOS only lets an app press keys and move the pointer for you with that permission. XPad uses it for nothing else and has no network access or analytics.

Will Steam see it as a gamepad?

Not yet. XPad sends keyboard and mouse input, so games see a keyboard. A true virtual gamepad needs a special entitlement from Apple.

It says the controller is in use by another app.

Only one app can use a USB controller at a time. Close the other app or browser tab and XPad connects by itself. Use Pause to hand the controller to another app.

Is it really free?

Yes. Free and open source (MIT). No ads, no account, no in-app purchases.
